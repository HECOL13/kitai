# 拼 PDD Inspector KZ — Анализ товаров Pinduoduo, Ботов и Цены в Тенге (KZT) с НДС

Веб-приложение (PWA) для проверки товаров и продавцов с китайского маркетплейса **Pinduoduo (拼多多)**, выявления накрученных комментариев (ботов / 刷单), сравнения товаров между собой и расчёта полной стоимости в **казахстанских тенге (₸) с учётом НДС РК (12% / 16%) и карго-доставки**.

Полностью готово для бесплатного размещения на **GitHub Pages** и добавления на главный экран **iPhone / Android / ПК**.

---

## 🚀 Основные возможности

1. **Проверка по ссылке Pinduoduo (`Copy Link`):**
   - Извлекает `goods_id`, цену и данные из ссылки вида `https://mobile.yangkeduo.com/goods.html?goods_id=...` или текста «Поделиться».
   - Проверяет открытые метаданные через цепочку прокси, а при блокировке WeChat-авторизацией позволяет за 2 секунды прикрепить скриншот с телефона или вставить отзывы для распознавания через **Google Gemini AI (Vision OCR)**.
2. **Анализ продавца и витрины магазина:**
   - Проверка бейджей: `百亿补贴` (Субсидия 10 млрд), `官方旗舰店` (Официальный флагман), `源头工厂` (Прямая фабрика), `假一赔十` (Штраф x10 за подделку).
   - Оценка 3 рейтингов DSR: описание (`描述相符`), сервис (`服务态度`), логистика (`物流服务`).
   - Проверка специализации витрины: продаёт ли магазин товары одной узкой категории или всё подряд («солянка» / дропшиппер).
3. **Детектор ботов и повторяющихся комментариев (刷单):**
   - Вычисляет процент дубликатов и шаблонных фраз (`物流很快，包装完好`, `习惯好评`, `质量很好，值得购买`).
   - Анализирует всплески отзывов по времени, долю живых фото/видео и дополнительных отзывов спустя месяц (`追评`).
   - Выводит **Индекс надёжности (0–100%)** и **Вероятность ботов (%)**.
4. **Калькулятор цены в Тенге (KZT ₸) с НДС РК и Карго:**
   - Автоматическое обновление курса **CNY → KZT** онлайн + возможность задать свой курс обмена Alipay/банка.
   - Расчёт **НДС Казахстана (12% стандартный / 16% новый / 0%)** в двух режимах: *«+ Сверху»* и *«В т.ч. НДС»*.
   - Учёт веса товара (кг), тарифа карго-доставки в РК (₸/кг) и комиссии байера/перевода.
5. **Сравнение товаров и История:**
   - Таблица сравнения до 4 товаров Pinduoduo бок о бок с автоматическим выбором победителя по цене в тенге и честности продавца.

## 🌐 Как запустить сайт на GitHub Pages (за 1 минуту)

1. Создайте новый репозиторий на [GitHub](https://github.com/new) (например, `pdd-inspector-kz`).
2. Загрузите в него файлы из этой папки:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.json`
   - `sw.js`
3. Перейдите в репозитории во вкладку **Settings → Pages**.
4. В разделе **Build and deployment → Branch** выберите ветку `main` (папка `/ (root)`) и нажмите **Save**.
5. Через 30–60 секунд ваш сайт будет доступен по ссылке `https://<ваш-логин>.github.io/pdd-inspector-kz/` с любого телефона или компьютера!
